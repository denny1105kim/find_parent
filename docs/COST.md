# 월 예상 비용 (분류)

이 앱은 **Firebase(Blaze 종량제) + Kakao 지도**를 쓴다. Cloud Functions 를 쓰므로
**Blaze 요금제(카드 등록)** 가 필요하지만, 소규모에서는 무료 한도 안이라 실제 청구는 0에 가깝다.
아래 단가는 근사치(2025 기준, 서울/asia-northeast3 유사)이며 실제는 사용량에 따라 변한다.

## 요약

| 규모 | 월 예상 비용 | 비고 |
|---|---|---|
| **1가족 (간병인1+환자1, 실사용)** | **약 $0 (0원)** | 모든 서비스 무료 한도 내. Blaze 등록만 필요 |
| 소규모 10가족 | 약 $0 | 여전히 무료 한도 내 |
| 100가족 | 약 $5~15 | 대부분 영상 다운로드 대역폭 |
| 1,000가족 (배포 규모) | 약 $100~130 | **영상 다운로드 대역폭이 대부분** |

가정: 한 페어가 하루 20건 요청(영상 절반=3MB, 나머지 소리/위치≈0.1MB), 한 달 30일.

## 핵심 포인트

- **당신의 실사용(가족 1~2명)은 사실상 무료.** 하루 수십~수백 건을 써도 무료 한도를 넘기 어렵다.
- **규모가 커지면 거의 전부 "영상 다운로드 대역폭" 비용**이다(간병인이 클립을 내려받을 때). 영상 1건 ≈ 3MB.
- 비용 줄이는 법:
  - 영상 비트레이트/화질을 더 낮춤(이미 SD·비트레이트 제한 적용됨)
  - 기본은 소리(60KB)로, 영상은 필요할 때만
  - 클립 3일 자동 삭제(수명주기)로 **저장** 비용 억제(대역폭과는 무관)
- **Blaze 요금제**: 카드 등록은 필수지만, 무료 한도 안이면 청구 0원. **예산 알림(Budget Alert)** 을 $5 등으로 걸어두면 안전하다.

## 주의
- Firestore/Storage **지역**과 시점에 따라 단가가 다르다. 정확한 값은 [Firebase 가격](https://firebase.google.com/pricing) 참고.
- 위 추정은 "간병인이 모든 클립을 즉시 내려받는다" 가정. 안 받으면 대역폭·저장 더 줄어든다.
